# RVR Global Logistics Website

## Goal
Build a contemporary, responsive multi-page website using the selected clay industrial direction and the supplied company content.

## Pages
- Home and About RVR
- Services overview plus nine individual service pages
- Industries and Network
- Track Shipment, Get a Quote, and Contact

## Experience
- Shared navigation and footer across every page, including a compact mobile menu
- Full-bleed cargo photography, warm clay palette, bold display typography, precise wayfinding details, and restrained route-inspired motion
- Clear links between services, quote requests, tracking, and contact
- Quote and tracking forms with useful front-end validation and confirmation states
- Missing address, phone, email, hours, statistics, and live tracking provider remain clearly identified rather than invented

## Technical approach
- Create reusable site shell, page hero, service detail, CTA, form, and content-section components
- Add one route per requested page with unique search and social metadata
- Generate and bundle cohesive freight imagery for the home and supporting pages
- Use semantic design tokens in the global stylesheet and preserve the selected visual composition
- Add small tests for page configuration and route coverage, then verify desktop and mobile rendering in the preview
